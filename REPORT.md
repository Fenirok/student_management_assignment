# Advanced Query Filtering with Django

Run the queries from the project directory:

```bash
python manage.py q_filter_demo
```

The management command prints each queryset’s results and the SQL generated by Django. SQL syntax may vary depending on the database backend. The examples below describe the SQL generated by the SQLite database used for this project.

## Queries

### 1. Italian or Mexican restaurants

The `italian_mexican_q` variable uses `Q` with the `__in` lookup to match either restaurant type.

```python
italian_mexican_q = Q(restaurant_type__in=["Italian", "Mexican"])
```

SQLite generates a condition like:

```sql
WHERE restaurant_type IN ('Italian', 'Mexican')
```

### 2. Restaurants not opened in the last 30 days

The command calculates a cutoff date 30 days before the current local date. `recently_opened_q` checks for restaurants opened on or after that date. The `~` operator negates the condition.

```python
recently_opened_q = Q(date_opened__gte=cutoff)
not_recently_opened_q = ~recently_opened_q
```

The SQL uses a `NOT` condition, for example:

```sql
WHERE NOT (date_opened >= '2026-09-12')
```

The date in the SQL changes when the command is run.

### 3. Italian/Mexican restaurants or restaurants opened recently

The command combines `italian_mexican_q` and `recently_opened_q` with `|`, which represents `OR`.

```python
Restaurant.objects.filter(italian_mexican_q | recently_opened_q)
```

The SQL uses both conditions joined by `OR`:

```sql
WHERE (restaurant_type IN ('Italian', 'Mexican') OR date_opened >= '2026-09-12')
```

### 4. Restaurant names containing “grill”

The `__icontains` lookup finds the substring without regard to letter case.

```python
Restaurant.objects.filter(name__icontains="grill")
```

SQLite generates a `LIKE` condition similar to:

```sql
WHERE name LIKE '%grill%'
```

### 5. Restaurant names ending with “Cafe”

The `__endswith` lookup finds names with the given suffix.

```python
Restaurant.objects.filter(name__endswith="Cafe")
```

SQLite generates a `LIKE` condition similar to:

```sql
WHERE name LIKE '%Cafe'
```

### 6. Restaurant names containing one or more digits

The `name_has_digit_q` variable uses Django’s `__regex` lookup. The regular expression `[0-9]+` matches one or more digits.

```python
name_has_digit_q = Q(name__regex=r"[0-9]+")
```

SQLite generates a regular expression condition similar to:

```sql
WHERE name REGEXP '[0-9]+'
```

### 7. Profitable sales or restaurants with a digit in the name

`profitable_q` compares each sale’s income with its expenditure. `restaurant_name_has_digit_q` checks the related restaurant’s name. The conditions are combined with `|`.

```python
profitable_q = Q(income__gt=F("expenditure"))
restaurant_name_has_digit_q = Q(restaurant__name__regex=r"[0-9]+")
profitable_or_named_with_digit_q = profitable_q | restaurant_name_has_digit_q
```

The queryset uses `select_related("restaurant")` to retrieve the related restaurant with a SQL join:

```python
Sale.objects.filter(
    profitable_or_named_with_digit_q
).select_related("restaurant")
```

The generated SQL includes an `INNER JOIN` to the restaurant table and an `OR` condition.
